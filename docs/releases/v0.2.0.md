# Rusty Git Client 0.2.0

The second release of Rusty Git Client. It adds repository tabs, Undo and Redo, a lot more you can do from the commit graph and the branch menus, single-line staging, a side-by-side diff, a new start screen and an app icon, and it is much faster on large repositories.

## Requirements
- **Git** installed and on your `PATH` (the app runs the system `git` for fetch, pull and push).
- Windows needs the WebView2 runtime (included in Windows 11).

## Downloads
- **Windows:** the setup installer (`…_x64-setup.exe`), the MSI, or the standalone `rusty-git-client.exe`.
- **macOS:** the `.dmg`, as built by the release pipeline.
- The builds are **not signed**. Windows SmartScreen shows "unknown publisher" (choose *More info*, then *Run anyway*), and macOS needs right-click, then *Open*, the first time.

## What's new in 0.2.0

### Tabs and the start screen
- **Repository tabs:** every open repository gets a tab at the top of the window. Switch between them, close them with the **×** or a middle-click, and open another with **+**. Only the active tab is live: background tabs do not auto-fetch.
- A new **start screen**: your recent repositories on the left, and on the right every repository found in a folder you choose (remembered between sessions), with a filter, the current branch and how long ago each was last committed to.
- A new **app icon**.

### Undo and Redo
- **↶ Undo** and **↷ Redo** buttons in the title bar (also `Ctrl`/`Cmd` + `Z` and `Ctrl`/`Cmd` + `Shift` + `Z`) take back and repeat what you did in the app: commits and amends, merges, fast-forwards, pulls, resets, rebases, renames, drops, checkouts, branch and stash actions, staging and discarding. Hover a button to see what it would undo. Undo refuses, and tells you why, if something else changed the repository in the meantime.

### Commit graph
- The commit you are on stands out, and commits outside the checked-out branch's history are faded.
- **Check out** a branch straight from the graph, from the right-click menu or by double-clicking its commit. Remote branches become local branches that track them.
- New right-click actions on a commit: **Checkout this commit**, **Cherry pick**, **Revert**, **Copy commit SHA** and **Fast-forward to this commit**.
- Right-click a commit that is a branch tip for **Delete branch** (local, or remote on the server), **Copy branch name**, **Merge** and **Rebase onto**.
- Stashes can be applied, popped or deleted from their graph menu.
- Much faster on large repositories: the graph loads in pages as you scroll, and ahead/behind counts and working-directory scans are cached and shared. The graph and the Changes panel show a loading state, and a branch switch locks the left panel until it finishes.

### Branches and remotes
- **Merge** a branch into the current one, **rebase** the current branch onto another, and **fast-forward** it, each from the branch menus, with a confirmation and the usual rule that conflicts cancel the operation and change nothing.
- **Clean up merged…** deletes the local or remote branches whose work is already in `main`, and **Delete synced branches** removes local branches identical to their upstream. Both list what they will delete first.
- Branch names with a `/` are grouped into folders, **Copy branch name** is in the branch menus, and the checked-out branch can now be renamed.
- Sidebar sections can be resized by dragging, and collapsed sections keep their headlines.
- Check out remote branches by double-clicking them.

### Committing and stashing
- A **Discard all** (trash) button beside **Stage all** throws away every unstaged change after a confirmation. Undo brings it back.
- A **Stash** button in the title bar, **Apply stash** (keeps the stash), and **Delete all stashes** in the Stashes menu.

### Diffs
- A **side-by-side** view next to Full file and Changes. The choice is remembered.
- **Stage line** and **Discard line** from the diff's right-click menu, for one line or for several lines you select with the mouse.
- **▲ / ▼** buttons jump between the changes in a file, and the marks along the scrollbar are clickable.
- **File history:** right-click a file, in the staging panel or in a commit, to list every commit that changed it (following renames) and open their diffs.

### Fetch, pull and push
- Pushing a branch that has diverged from its upstream opens a dialog that offers a **Force push** (with lease) or **Cancel**, instead of just failing.
- When git needs a username, password, token or SSH passphrase and no credential helper provides it, a sign-in dialog asks for it (macOS; Windows keeps using Git Credential Manager).

### Other
- Spellcheck and autocomplete are off in the commit message boxes.
- `npm run build:run` builds the release version and starts it (for people building from source).

## Known limitations
- No conflict-resolution screen yet: conflicting pulls, merges, rebases, cherry-picks and reverts are cancelled, and you resolve them in the terminal.
- Not built yet: tags in the sidebar, unstaging a single line, syntax highlighting and intra-line diff highlighting.
- Undo and Redo only cover what you do in the app, and only while it is open. Fetch, push and changes to remotes (including deleting remote branches) cannot be undone.
- Dropping, moving or resetting commits needs a clean working directory.
- Switching tabs does not keep a tab's open diff, selected commit or terminal session.
- On macOS the icon shows only in a bundled `.app` or `.dmg`, not when run with `tauri dev` or `npm run build:run`.
- Only English.
