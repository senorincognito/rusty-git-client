# Settings

- Open **Settings** with the ⚙ button (right end of the tab bar, or the start screen's header) or `Ctrl`/`Cmd` + `,`.
- Every change applies and is saved at once; the dialog only has a **Close** button.
- **Agents**: the list behind *Start agent* in the Worktrees section (see [Worktrees](worktrees.md)). Each has a name and the command typed into the worktree's terminal; add, edit, remove and reorder them with the buttons at the row's end. The first one is the default for new worktrees. Claude Code, Codex, Aider and pi are there to begin with. The programs must be installed, on your `PATH` and signed in; the app only types the command.
- **Terminal → Suggest branches and tags** (on by default): see [Terminal](terminal.md).
